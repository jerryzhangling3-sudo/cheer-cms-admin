Thresholds (Upgrade AND · Downgrade OR · see PRD §4.6)

Relationships may extend indefinitely; these thresholds only include direct and level 1–3 downline, excluding the current Partner.
Upgrade: active ≥ threshold AND margin ≥ threshold
Downgrade: active < threshold OR margin < threshold (both survive → hold)
Non-Partner tiers have no thresholds: L1 is auto-granted at account creation, no evaluation required. Only the name is editable here.
